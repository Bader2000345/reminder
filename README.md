# فريق مُذكّر (mudhakkir-dev)

تطبيق لحالو لفريق مُذكّر: رسائل المستخدمين («ملاحظات وشكاوي»)، والرد عليها، والأرقام، والإعلانات، والفريق.
بيتثبّت عالجوال متل مُذكّر. الرابط: **https://bader2000345.github.io/mudhakkir-dev/**

> هالمجلد بينرفع لريبو **لحالو** اسمو `mudhakkir-dev` على GitHub (مو لريبو `reminder`).
> هو ومُذكّر على نفس الموقع (`bader2000345.github.io`)، فالسيرفر ما بدو أي تغيير بالـ CORS.

## مين بيقدر يعمل شو
| | قارئ | مجاوب | مشرف | صاحب التطبيق |
|---|---|---|---|---|
| يقرا الرسائل | ✓ | ✓ | ✓ | ✓ |
| يرد ويأرشف | | ✓ | ✓ | ✓ |
| الأرقام والفحص، والإعلان | | | ✓ | ✓ |
| يعمل رموز ويلغيها، وأجهزتك | | | | ✓ |

- **الدخول:** كل شخص إلو رمز 8 حروف وأرقام (`XXXX-XXXX`، بلا 0 و O و 1 و I).
  - الرمز لجهاز واحد: أول جهاز بيدخل فيه بيمسكو.
  - الرمز دايم لحتى صاحب التطبيق يلغيه.
- **صاحب التطبيق** بيدخل من «أنا صاحب التطبيق» بكلمة السر (Secret اسمه `DEV_KEY` بـ Cloudflare).
  - الحد جهازين.
  - إذا كان فاتح صفحة المطوّر القديمة بمُذكّر على نفس المتصفح، بيفوت لحالو.
- **الرمز بيطلع مرة وحدة** وقت ينعمل (نسخ أو مشاركة)، والسيرفر بيخزّن بصمتو بس. إذا ضاع، بتعمل واحد جديد.
- **الرد** بيوصل للمستخدم بمُذكّر باسم «فريق مُذكّر»، والفريق بيشوف مين ردّ.
- **إذا غيّر حدا جوالو:** الفريق ← «⋯» جنب اسمو ← «فك الجهاز»، وبيدخل بنفس الرمز من الجديد.
- **إذا ضاع جوالك إنت:** غيّر `DEV_KEY` بـ Cloudflare.
  - بتطلع كل أجهزتك وكل الفريق من أجهزتهن.
  - الفريق بيرجع يدخل بنفس رموزو.

## النسخة 2 (مع مُذكّر 31)
- **تثبيت متل مُذكّر:** بطاقة فيها زر «تثبيت التطبيق» والطريقة لجهازك.
  - وين: بشاشة الدخول، وفوق الرسائل (فيها «لاحقًا»)، وبـ«حسابي».
  - بمتصفح شاومي وأوبو وفيفو وهواوي، وجوّا إنستغرام وفيسبوك بأندرويد: الزر بيصير «افتح بـ Chrome»، لأنها ما بتثبّت.
  - بأندرويد: «ثبّتو وما طلعت الأيقونة؟» بخطوات كل شركة، وشركة جوالك مفتوحة لحالها.
- **الكتابة ما بتكبّر الشاشة:** كل الخانات خطها 16، لأنو الآيفون بيكبّر لما يكون أصغر.
  - وقت الكتابة الشريط تحت بيختفي، والكيبورد ما بيغطّي خانة الرد.
- **الكبسات:** كل زر بيصغر شوي لما تكبسو، والأزرار أكبر (44 وفوق)، والكبس السريع ما بيكبّر الشاشة.
- **الضغط المطوّل ما بيحدّد ولا بينسخ.** لنسخ رسالة: زر «نسخ النص».
- **أيقونة الإشعار الصغيرة** (`icons/badge-96.png`): قوسين بيض على شفاف. الملوّنة كانت تطلع مربّع بأندرويد.
- **الأرقام ← الفحص** بيبيّن تخزين السيرفر (KV أو D1، وقديش انتقل)، وقديش بيلحق يبعت بالدقيقة، وإذا وصلنا للحد.

## النسخة 3 (مع مُذكّر 32): الألوان الجديدة
- نفس ألوان مُذكّر 60-30-10 (ل2 «زمرّد وعاج» ق1، مخففة): خلفية عاجي، بطاقات زمرّدي فاتح، وذهبي للأزرار. بالليل حبر زمرّدي.
- `--ac` ذهبي للأزرار والشارات، و`--ac-ink` للكتابة المميّزة (الروابط، «كل الرسائل»، الشريط تحت): زمرّدي بالنهار وذهبي بالليل.

## الملفات
| الملف | شو فيه |
|---|---|
| `index.html` | الصفحة: الدخول (8 خانات) والهيكل |
| `app.css` | نفس ألوان وخطوط مُذكّر، فاتح وداكن حسب الجهاز |
| `app.js` | كل شي: الدخول، الرسائل كمحادثة، الأرقام، الإعلان، الفريق، الإشعارات |
| `sw.js` | حفظ الملفات للفتح السريع، وإشعار «رسالة جديدة» |
| `manifest.json` | الاسم «مُذكّر · المطوّر» والأيقونات |
| `icons/` | قوس مُذكّر زعفراني على خلفية ليلية، و`badge-96.png` لشريط الحالة |

## التحديث
غيّر `CACHE` بـ `sw.js` (مثلًا `mdt-v2`) و `VERSION` بـ `app.js` مع كل تعديل، حتى يوصل للأجهزة.

## السيرفر
نفس سيرفر مُذكّر (`worker.js` بـ Cloudflare، الإصدار 29 وفوق).

| الطريق | شو بيعمل |
|---|---|
| `/team/login` | دخول بالرمز |
| `/team/me` | مين أنا ودوري |
| `/team/list`، `/team/create`، `/team/update` | الفريق (لصاحب التطبيق) |
| `/dev/*` | الرسائل والأرقام والإعلان، كل واحد بأقل دور بيفتحو |

## التجربة على الكمبيوتر
من مجلد مُذكّر (أدوات بس، ما بتنرفع):
1. `node tools/serve-worker.mjs`: سيرفر وهمي مع رسائل وفريق تجريبي.
2. `node tools/serve.mjs 5192 "<مسار هالمجلد>"`: بيشغّل هالتطبيق.
3. افتح `http://127.0.0.1:5192/index.html?api=http://127.0.0.1:8787`.
4. `node tools/shot.mjs tools/plans/team-app.json`: بيجرّب كل الأدوار وبياخد صور.
5. `node tools/shot.mjs tools/plans/team-v2.json`: التثبيت (كأنو ريدمي ومتصفح شاومي)، وخط الكتابة، والفحص الجديد.
