# مُذكّر — دليل المشروع

تطبيق ويب (PWA) للقرآن الكريم والأذكار والتذكير، مع المساعد «اسأل مُذكّر».
الموقع: https://bader2000345.github.io/reminder/

## خريطة الملفات

```
index.html                  ← الهيكل والمحتوى فقط (الصفحات، النوافذ، الأزرار)
manifest.json               ← اسم التطبيق وأيقوناته عند التثبيت
sw.js                       ← Service Worker: الإشعارات والتطبيق مغلق + العمل دون اتصال
version.json                ← رقم الإصدار و«ما الجديد» (لإشعار الناس بالتحديث)
general-adhkar.js           ← الأذكار العامة (٤٦ ذكرًا) مع أدلتها
adhkar-data.js              ← أذكار الأقسام (الصباح، المساء، الصلاة، النوم…) مع الأحاديث
situations-adhkar.js        ← أذكار المناسبات (٢٦ موقفًا: الغضب، الهم، السفر، المطر…) مع أدلتها
worker.js                   ← سيرفر Cloudflare: الإشعارات + المساعد (/chat) + التفسير (/tafsir)
                              (يُنسخ إلى Cloudflare، لا يُرفع للموقع ضرورةً)

assets/img/                 ← الشعار والأيقونات
assets/css/                 ← التنسيقات (بالترتيب، كل ملف يعدّل على ما قبله)
   01-base.css                  الأساس: الهيكل، البطاقات، الأزرار، النوافذ
   02-reader-and-palette.css    وضع القراءة الحرة وألوان أولى
   03-home-and-wird.css         الرئيسية والورد اليومي
   04-brand-and-effects.css     الشعار، الخلفية، ميل البطاقات، المشاركة
   05-viewer-reminders-picker.css  عارض الأذكار، بطاقات التذكير، التقويم، التنبيه
   06-immersive-and-mobile.css  ملء الشاشة، شريط التنقل، الجوال، الحركات النابضية
   07-design.css                ← التصميم الحالي: الألوان والخط والخلفية (ابدأ منه لأي تعديل شكل)
   08-quran-tools.css           أدوات القرآن: تنسيق المصحف، أدوات الآية، التفسير، التجويد، البحث
   09-assistant.css             «اسأل مُذكّر»، أذكار المناسبات، بطاقة الجمعة، الاسم
assets/js/                  ← المنطق (بالترتيب، main.js آخرها)
   preload-theme.js             يطبّق الوضع الداكن قبل الرسم
   splash.js                    شاشة البداية
   knowledge.js                 فهرس محتوى التطبيق والبحث فيه (يفهم العامية) — يستخدمه المساعد و sw.js
   core.js                      التنقل، البحث، الوضع الغامر
   adhkar-viewer.js             عارض الأذكار والعدّاد، وقائمة أذكار المناسبات
   theme.js                     المظهر (فاتح/داكن/الجهاز/الشمس)
   modals-and-picker.js         النوافذ والتقويم ومنتقي الوقت
   wird.js                      الورد اليومي والختمة
   quran-tools.js               أدوات القرآن: اللوحة المنبثقة، التجويد، التفسير، أدوات الآية، العلامات، البحث، أدوات وضع التركيز
   reader.js                    القراءة الحرة و«تنسيق المصحف»
   notifications.js             الإشعارات والسيرفر (PUSH_SERVER في أوله)
   reminders.js                 أذكاري (التذكيرات الشخصية)
   updates.js                   إشعار التحديثات (APP_BUILD في أوله)
   install.js                   زر تثبيت التطبيق والطريقة لكل جهاز
   home.js                      الرئيسية والمسبحة والإحصائيات
   share.js                     صورة المشاركة
   time-context.js              التحية (مع اسمك)، الأذكار حسب الوقت، تذكير الجمعة
   motion.js                    الحركات والخلفية ونقاط النور
   assistant.js                 المساعد «اسأل مُذكّر»
   main.js                      تشغيل كل شيء
```

## أين أعدّل؟

| أريد أن… | الملف |
|---|---|
| أغيّر الألوان أو الخط | `assets/css/07-design.css` (المتغيرات في أوله) |
| أضيف ذكرًا أو أعدّل دليلًا | `adhkar-data.js` أو `general-adhkar.js` |
| أضيف موقفًا لأذكار المناسبات أو كلمات يبحث بها الناس | `situations-adhkar.js` (`keywords`) |
| أغيّر نصًا أو زرًا في صفحة | `index.html` |
| أغيّر رابط السيرفر | `assets/js/notifications.js` ← `PUSH_SERVER` (ونفس الرابط في أول `sw.js`) |
| أغيّر نموذج الذكاء أو تعليماته | `worker.js` ← `AI_MODEL` و `ASSISTANT_RULES` |

## المساعد «اسأل مُذكّر» (Cloudflare Workers AI — مجاني)

إعداد لمرة واحدة في Cloudflare:
1. Workers & Pages ← الـ Worker (mudhakkir-push) ← **Settings ← Bindings ← Add ← Workers AI**، والاسم **`AI`** بالضبط.
2. انسخ محتوى `worker.js` الجديد إلى الـ Worker واضغط **Deploy**.

كيف يعمل:
- التطبيق يبحث أولًا في محتوى الموقع (`knowledge.js`) ويرسل أقرب الأذكار مع السؤال وآخر ١٢ رسالة.
- النموذج يكتب شرحًا قصيرًا ويشير للأذكار بوسوم مثل `[[sit-anger:0]]`، والتطبيق يعرض **نص الذكر ودليله من بيانات الموقع نفسها** (لا من النموذج).
- الحصة المجانية: ١٠٬٠٠٠ «نيورون» يوميًا (≈ ٩٠ رسالة لكل الموقع)، وحد ٢٠ رسالة يوميًا لكل جهاز.
  عند نفادها، أو دون إنترنت، يجيب التطبيق من محتواه مباشرة.
- المحادثة محفوظة في جهاز المستخدم فقط (آخر ٤٠ رسالة)، وزر ✎ يبدأ محادثة جديدة.

## عند نشر تحديث جديد

1. في `version.json`: زد `build` بواحد واكتب الجديد في `notes`.
2. في `assets/js/updates.js`: ضع **نفس الرقم** في `APP_BUILD`.
3. في `sw.js`: زد رقم `CACHE` (مثلًا `mudhakkir-v16` ← `mudhakkir-v17`). **ضروري**: بدونه لا يعرف التطبيق أن هناك تحديثًا.
4. ارفع الملفات المعدّلة إلى GitHub.

### ماذا يحدث عند المستخدمين؟
- التطبيق **لا يتحدّث وحده**: يبقى على نسخته المحفوظة حتى لو أُغلق وفُتح.
- الملفات الجديدة تُنزَّل في الخلفية، ثم يظهر شريط **«تم تنزيل تحديث جديد»** وزر **«تحديث»**
  (ويظهر الزر أيضًا في الإعدادات ← التحديثات).
- بعد الضغط يفتح التطبيق على الجديد وتظهر **«ما الجديد»** مع رابط المشاركة.
- من لم يفتح التطبيق يصله إشعار «تحديث جديد لمُذكّر» (مرة واحدة لكل تحديث).

> عند إضافة ملف CSS أو JS جديد: أضفه في `index.html` (بالترتيب الصحيح) وفي قائمة `CSS_FILES` أو `JS_FILES` داخل `sw.js`.

## الإشعارات

- **الأذكار العامة كل ١٥ دقيقة** فيها زرّان: «✍️ اسأل مُذكّر» و«ذكر آخر».
  الكتابة داخل الإشعار نفسه ميزة تجريبية لا تدعمها أغلب الهواتف حاليًا (ولا الآيفون)،
  لذلك الزر يفتح المحادثة مباشرة والمؤشر في خانة الكتابة؛ وإن دعم المتصفح الكتابة يصل الجواب كإشعار.
- **تذكير الجمعة**: الجمعة ٩:٠٠ صباحًا بتوقيت الجهاز، يُرسل للسيرفر كتذكير عادي، وزر «اقرأ الكهف» يفتح صفحة ٢٩٣.
